# 通勤路上通过飞书指挥 OpenClaw 完成生图任务 — storyboard

## 统一角色设定（角色 bible）
- 主角：林舟，29岁男性项目经理，黑色短发微卷，细框眼镜，肤色偏白，表情灵活，略带困意但反应快；固定穿着：米白色风衣、雾蓝衬衫、深灰西裤、白色运动鞋、黑色斜挎包；固定道具：手机、无线耳机、咖啡杯、工牌。

## 统一画风规范
- 画风：现代都市轻喜剧漫画，2D干净线条，轻微赛璐璐上色，温暖晨光，奶油黄、地铁灰蓝、晨光橙、办公室木色，镜头清爽、叙事明确。

## UI 表现规则
- 规则：手机界面只表现为抽象协作聊天UI、任务卡、进度卡、图片缩略图，不出现真实品牌logo，不拟人化OpenClaw。

## 6 格剧情骨架
1. 家门口：清晨公寓门口，林舟一手拿咖啡一手看手机，刚收到“今天上班前交付6张连贯漫画图片包”的需求，在抽象协作聊天界面中给OpenClaw发出任务。
2. 地铁站台：地铁站台晨光偏冷，林舟站在安全线后查看手机，OpenClaw回传6个任务卡片与分镜草图缩略图。
3. 地铁车厢：地铁车厢内，林舟扶着立杆，耳机戴着，手机里出现中文提示词卡片，他让OpenClaw调用图片模型先生成第1张探针图。
4. 接驳公交/步行段：出站后的接驳步行段，城市街景掠过，林舟一边快步走一边审看手机上的图片缩略图与修改建议卡。
5. 写字楼门口：写字楼玻璃门前，林舟停步刷工牌，手机收到进度卡与群同步预览通知，他让OpenClaw把最终预览包同步到项目群。
6. 办公室工位：办公室工位前，林舟坐下放好包，桌上电脑刚亮，手机显示6张图片全部完成并打包交付，故事闭环。
