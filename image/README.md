# Demo image assets

This directory contains generated demo assets for `luban-skills` workflows.

## Contents

- `1.png` to `4.png`: standalone demo images.
- `commute-feishu-openclaw-imagegen-comic/`: a multi-frame image generation demo, including frames, a contact sheet, storyboard, render metadata, and validation output.

These files are examples and are not required to run the core `luban-skills` scripts.

## Notes for contributors

Do not commit generated assets that contain private prompts, internal paths, personal data, real webhook URLs, or credentials. Use relative paths or placeholders such as `<workspace>` in metadata and validation files.
