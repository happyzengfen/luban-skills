# Luban 多图连贯漫画任务 Prompt 模板

## 用途
用于给 Luban / Hermes 下发 **6格或多格连续漫画** 任务，避免任务目标漂移成“先出方案，生图只是顺手尝试”。

---

## 直接可用模板

```markdown
你现在要完成一个 **多图连贯漫画正式交付任务**，不是纯方案策划任务。

# 任务主题
生成一组 6 张连贯漫画，主题为：
[在这里写题目，例如：上班族在通勤路上通过飞书指挥 OpenClaw 完成工作事项]

# 主交付目标（必须达成）
1. 产出 6 张实际图片文件到指定目录
2. 6 张图角色一致、服装一致、画风一致、手机UI一致
3. 6 张图剧情连续，形成完整时间线
4. 每张图都可以单独重生成，不依赖整批一次成功
5. 只有全部图片文件成功落盘，才算正式完成

# 允许的降级路径（仅在后端异常时）
如果图片后端异常，可以降级输出：
- 统一角色设定
- 统一画风规范
- 分镜脚本
- 每张图最终提示词

但必须明确标记为：
- 方案版：只有文本方案和提示词
- 预览版：已有部分图片文件
- 正式版：6 张图片全部落盘

注意：只有方案版或预览版时，不得表述为“任务已正式完成”。

# 执行顺序（必须遵守）
## Step 1. 先锁定统一设定
先产出以下内容：
- 主角角色 bible（年龄、外貌、发型、服装、道具）
- 统一画风规范（色彩、线条、镜头感、光线）
- UI 表现规则（例如抽象协作聊天界面，不复刻真实 logo）
- 6 格剧情骨架

## Step 2. 先做单图探针
先只生成第 1 张，并验证：
- 后端能否成功返回图片
- 是否真的落盘到输出目录
- 风格是否符合预期
- 是否具备继续做 2-6 张的条件

如果第 1 张探针失败：
- 停止整批渲染
- 汇报失败证据
- 输出方案版，不要假装完成

## Step 3. 逐张生成，不要整批绑定
探针成功后，再逐张生成第 2-6 张。
要求：
- 每张图独立请求
- 每张图独立超时
- 每张图独立落盘
- 每张图独立记录成功/失败

不允许把 6 张图绑成一个长串行过程，导致超时后 0 文件。

## Step 4. 最终交付必须带状态分级
最终只允许以下三种状态：
- 正式版：6/6 图片全部落盘
- 预览版：部分图片成功落盘
- 方案版：仅有分镜和提示词

并且必须写清楚：
- 输出目录
- 已成功图片文件列表
- 失败图片编号
- 阻断原因
- 下一步最小恢复动作

# Prompt 编写规则
每张图提示词必须包含：
1. 全局角色锚点
2. 全局画风锚点
3. 当前场景描述
4. 当前动作/情绪
5. 当前对白或屏幕文字
6. 连续性约束（与上一张保持一致）
7. 禁止项（不得复刻真实 logo 等）

# 输出要求
最终输出必须包含：
1. 统一角色设定
2. 统一画风规范
3. 6 格剧情结构
4. 每张图最终提示词
5. 图片落盘结果
6. 交付状态（正式版 / 预览版 / 方案版）
7. 阻断证据（如失败）

# 输出目录
[在这里填绝对路径，例如：<workspace>/outputs/xxx]
```

## 这份模板解决的核心问题
1. 把“成图落盘”前置为主成功标准
2. 把“storyboard/提示词”明确降为兜底产物
3. 强制先做单图探针，避免后端未验证就 6 连发
4. 强制逐张落盘，避免整批超时后 0 文件
5. 强制把结果标记为正式版 / 预览版 / 方案版，避免 partial 被误报为完成
